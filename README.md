# 픽사 스토리 자판기

픽사 장편 **31편(1995–2026)**의 컨셉·등장인물·세계관·창작 장치를 한곳에서 검색하고 비교하며, **픽사 세계관을 닮은 이야기를 직접 설계**하는 창작 워크벤치입니다. 자판기에서 상품을 고르듯 작품 코드를 입력하거나 포스터를 선택하고, 최대 네 작품을 나란히 뜯어본 뒤, 창작 실험실에서 내 이야기의 뼈대를 세울 수 있습니다.

> 이 프로젝트는 픽사의 공식 서비스가 아닌 독립적인 창작 리서치·교육 도구입니다. 작품 정보의 출처는 각 상세 화면에 연결된 Pixar Animation Studios 공식 페이지이며, 화면의 포스터는 저작권 보호를 위해 직접 만든 추상 SVG입니다.

## 주요 기능

### 1. 진열대 — 찾기

- **통합 검색**: 제목·연도·주제·인물·역할·장소·태그·창작 장치·스토리 스파인까지 한 번에 검색하고, 제목이 걸리면 결과에 하이라이트를 표시합니다.
- **주제 필터(복수 선택)**: 10가지 고정 주제를 여러 개 동시에 켤 수 있고, 칩마다 해당 주제의 작품 수를 보여 줍니다.
- **정렬**: 오래된순 / 최신순 / 가나다순
- **카드에서 바로 담기**: 상세를 열지 않고도 카드 우측 상단 버튼으로 비교 트레이에 담습니다.
- **자판기 키패드**: 행 문자 + 번호(A1~H3)로 작품을 뽑습니다. 키보드로 문자·숫자를 직접 눌러도 되고, 랜덤 뽑기도 있습니다. 평소에는 접혀 있어 검색을 가립니다.
- **출고구**: 최근 열어 본 작품을 최대 6편까지 보관하며, 원할 때 지울 수 있습니다.

### 2. 비교 트레이 — 견주기

최대 4편을 가로로 놓고 **컨셉 문장 · What-if · 세계의 규칙 · 원하는 것 · 필요한 것 · 창작 장치 · 주요 인물 · 주요 세계 · 규모**를 항목별로 비교합니다. 트레이가 비어 있으면 31편의 한 줄 요약을 보여 줍니다. 작품이 많아졌으므로 담을 작품을 검색할 수 있고, **무작위 3편**·**같은 주제끼리 담기**로 빠르게 구성을 바꿀 수 있습니다.

### 3. 창작 실험실 — 만들기 ★ 신규

픽사 세계관과 비슷한 이야기를 쓰려는 사람을 위한 작업대입니다. 입력한 내용은 **이 브라우저에만 저장되며 서버로 전송되지 않습니다.**

- **스토리 스파인 빌더** — 픽사 스토리 아티스트들이 피칭에 쓰던 여섯 문장 구조(옛날 옛적에 / 매일 / 그러던 어느 날 / 그래서 / 그래서 / 마침내)를 채워 넣습니다. 각 칸에 무엇을 써야 하는지 안내와 예시 문장이 붙고, 31편 중 아무 작품이나 골라 **실제 스파인을 예시로 겹쳐 보거나 내 칸에 채워 넣고** 단어만 바꿔 가며 연습할 수 있습니다. 자동 저장되며 복사·텍스트 저장이 가능합니다.
- **What-if 프리미스 생성기** — “만약 ○○에게 마음이 있다면?”이라는 픽사식 출발점을 만듭니다. **주체 / 주인공의 내면 / 세계의 규칙 / 균형을 깨뜨리는 사건** 네 재료를 무작위 조합하고, 마음에 드는 재료는 자물쇠로 고정합니다. 만든 프리미스는 스파인 1~3번 칸으로 바로 옮길 수 있습니다.
- **이야기를 만드는 22가지 원칙** — 픽사 스토리 아티스트 엠마 코츠(Emma Coats)가 공개한 스토리텔링 원칙을 한국어로 정리하고, 각 원칙이 잘 드러나는 작품을 짝지었습니다.
- **창작 패턴 색인** — 31편에서 반복되는 설계 습관 8가지(세계의 규칙 하나로 밀기, 결점이 곧 해결책, 정반대의 짝, 공간이 감정을 말한다, 원하는 것 vs 필요한 것, 악당은 주인공의 그림자, 시한을 눈에 보이게, 마지막에는 놓아 주기)와 그 패턴을 지금 쓰는 이야기에 던질 **점검 질문**을 제공합니다.

### 4. 작품 상세 — 창작 해부

기존의 컨셉·인물·세계에 더해 각 작품마다 다음을 정리했습니다.

- **What if** — 그 작품이 출발한 한 줄 질문
- **원하는 것(Want) vs 필요한 것(Need)** — 주인공의 겉 목표와 실제 결핍
- **세계를 굴리는 규칙** — 어기면 큰일 나는 설정 한 줄
- **스토리 스파인 6단계** — 두 시간짜리 영화를 여섯 문장으로 압축한 것

상세 화면에서는 **이전/다음 작품 이동**(←/→), **창작 노트 텍스트 복사**, **이 작품으로 스파인 연습하기**(창작 실험실로 예시가 채워진 채 이동)를 할 수 있습니다.

### 5. 상태 유지와 공유

- **링크 공유**: 검색어·주제·정렬·비교 목록·열려 있는 작품이 URL 쿼리에 반영됩니다. 상단 **현재 화면 링크 복사** 버튼으로 지금 보고 있는 화면을 그대로 전달할 수 있습니다. 예) `?film=coco&theme=가족·세대`
- **자동 저장**: 최근 본 작품, 비교 트레이, 스토리 스파인 초안, 정렬 방식을 `localStorage`에 보관합니다. 검색어와 주제 필터는 **일부러 저장하지 않아** 다시 방문했을 때 걸러진 목록에 놀라지 않게 했습니다.
- 최근 기록은 출고구의 **기록 지우기**로, 스파인 초안은 **모두 지우기**로 언제든 삭제할 수 있습니다.

## 실행 방법

별도의 빌드 과정이나 패키지 설치가 필요 없는 단일 HTML 애플리케이션입니다.

`index.html`을 브라우저에서 열면 되지만, 브라우저 정책과 개발자 도구 사용 편의를 위해 로컬 서버 방식을 권장합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 <http://localhost:4173>에 접속합니다.

## 키보드와 접근성

- `Tab`: 버튼, 검색창, 링크 순서대로 이동
- `←` / `→` / `Home` / `End`: 상단 탭(진열대·비교 트레이·창작 실험실)과 창작 실험실 안쪽 탭 전환
- 상세 화면에서 `←` / `→`: 이전 · 다음 작품으로 이동
- 키패드가 열려 있을 때 `A`~`H`, `1`~`4`: 코드 직접 입력
- `Enter` / `Space`: 카드, 필터, 키패드 실행
- `Esc`: 열린 작품 상세 닫기
- 상세 화면 안에서 `Tab`을 계속 눌러도 포커스가 모달 밖으로 나가지 않으며, 닫으면 원래 카드로 돌아옵니다.
- 모든 조작 요소는 최소 터치 영역 44px을 확보했습니다.
- 어두운 자판기 표면 위의 모든 텍스트는 명도 대비 4.5:1 이상입니다(측정치 6.07~12.94:1).
- 포스터 SVG는 `aria-hidden` 처리해 카드 이름이 중복 낭독되지 않습니다.
- 운영체제에서 **동작 줄이기**를 설정한 경우 출고 애니메이션과 전환 효과를 제거합니다.
- 외부 아이콘 폰트를 불러오지 못하면(오프라인·CDN 차단) 합자 원문이 깨져 보이는 대신 짧은 글자 대체본으로 자동 전환됩니다.
- 상세 화면은 인쇄용 스타일을 제공합니다(브라우저 인쇄 시 자판기 UI 제외).

## UI/UX 점검 및 개선 보고서

이번 점검은 **작품 수가 8편에서 31편으로 늘어났을 때 무너지는 지점**과, **창작자가 실제로 무엇을 하러 오는가**를 중심으로 진행했습니다.

| 낮음 | 조사 결과를 공유할 방법이 없음 | 수업·협업에서 화면을 말로 설명해야 함 | URL 쿼리 동기화 + 링크 복사 버튼 |

### 창작 지원 관점의 개선

| 발견한 문제 | 적용한 개선 |
| --- | --- |
| 자료를 “읽는” 것에서 끝나고 자기 이야기로 옮길 통로가 없음 | 창작 실험실 탭 신설(스파인 빌더·What-if 생성기·원칙 22·패턴 색인) |
| `core` 한 줄만으로는 왜 그 장치가 작동하는지 알기 어려움 | 작품마다 What-if / Want / Need / 세계의 규칙 / 스토리 스파인 6단계를 추가 |
| 비교 항목이 표면 정보(인물 수·세계 수) 위주 | 비교 축을 What-if·세계의 규칙·Want·Need로 교체·확장 |
| 원칙을 알아도 자기 이야기에 적용할 계기가 없음 | 패턴마다 “점검 질문”을 붙이고, 상세→실험실, 생성기→스파인으로 이어지는 동선 연결 |
| 작업물을 밖으로 꺼낼 수 없음 | 창작 노트 복사, 줄거리 복사, 텍스트 파일 저장 지원 |

### 앞으로 권장하는 후속 개선

1. **데이터 분리**: `FILMS`가 커졌으므로 JSON으로 분리하고 스키마 검증을 붙이면 콘텐츠 수정 오류를 줄일 수 있습니다. 다만 `file://`로 바로 열리는 장점은 잃습니다.
2. **여러 개의 스파인 초안**: 지금은 초안 하나만 저장됩니다. 이름을 붙여 여러 편을 보관·전환하는 기능이 유용합니다.
3. **자동화된 접근성 회귀 검사**: Playwright + axe-core를 CI에 붙여 포커스·이름/역할/값·대비를 지속 점검.
4. **다국어 모드**: 영문 UI 전환을 추가하면 원제·원문 태그라인 활용도가 올라갑니다.
5. **인물 관계도**: 인물 데이터의 `r`(역할)을 축으로 작품 간 역할 유형을 교차 조회.

## 작품 추가 방법

`index.html`의 `FILMS` 배열에 객체를 추가합니다. 슬롯 코드, 검색 인덱스, 주제 칩과 개수, 키패드 행, 비교 트레이, 창작 실험실 예시 목록은 작품 연도순 정렬 결과를 기준으로 모두 자동 갱신됩니다.

```js
{
  id: 'wall-e',                       // 고유 영문 식별자
  ko: '월-E',                          // 한국어 제목
  en: 'WALL·E',                        // 원제
  year: 2008,
  theme: '자연·문명',                   // THEME_ORDER 중 하나 (필터 칩)
  tags: ['로봇','사랑','환경'],          // 검색 전용 보조 키워드
  src: 'https://www.pixar.com/wall-e', // 공식 정보 출처
  tagline: 'Original tagline',
  taglineKo: '한국어 태그라인',
  concept: '이야기의 출발점 (2~3문장)',
  core: '창작 관점에서 눈여겨볼 장치',
  whatif: '만약 …라면?',                // 한 줄 프리미스
  want: '주인공이 원하는 것 (겉 목표)',
  need: '주인공에게 실제로 필요한 것',
  rule: '세계를 굴리는 규칙 한 줄',
  spine: ['옛날 옛적에…','매일…','그러던 어느 날…','그래서…','그래서…','마침내…'],
  palette: ['#배경','#주색','#보조색','#글자색'],
  shape: 'orbit',                     // 자동 포스터 모티프 (POSTER_SHAPES 키)
  poster: POSTER(...),                // 선택: 직접 디자인한 포스터
  people: [{ n: '이름', r: '역할', d: '설명' }],
  worlds: [{ n: '장소', d: '설명' }]
}
```

`shape`로 고를 수 있는 자동 포스터 모티프: `orbit` · `waves` · `arch` · `stripes` · `star` · `peak` · `grid` · `bloom` · `spark` · `door` · `road`

### 콘텐츠 작성 원칙

- 공식 작품 페이지를 우선 출처로 사용합니다.
- 번역문은 직역보다 한국어 가독성을 우선하되 의미를 임의로 확장하지 않습니다.
- 인물과 세계 설명은 스포일러 수준을 일관되게 유지합니다. 단, `spine`과 `need`는 구조 학습이 목적이므로 결말을 포함합니다.
- 포스터에는 공식 키아트를 복제하지 않고 작품의 색과 추상 모티프만 활용합니다.
- `id`는 중복되지 않아야 하며, 연도는 숫자로 입력합니다.

## 기술 구성

- HTML5
- CSS Custom Properties, Grid, Flexbox, 반응형 미디어 쿼리, 인쇄 스타일
- Vanilla JavaScript (프레임워크 없음, 빌드 없음)
- 인라인 SVG 포스터
- `localStorage` · `URLSearchParams` · `Clipboard API` (모두 실패 시 조용히 대체 동작)
- Pretendard 웹폰트 및 Material Icons (외부 CDN, 실패 시 자동 대체)

핵심 기능은 외부 프레임워크 없이 동작합니다. 네트워크 연결이 없으면 외부 폰트와 아이콘은 로드되지 않지만, 작품 데이터와 모든 인터랙션은 `index.html`에 포함되어 있으며 아이콘은 글자 대체본으로 전환됩니다.

## 데이터 출처에 관한 안내

작품 정보는 각 작품의 Pixar Animation Studios 공식 페이지(`https://www.pixar.com/<slug>`)를 1차 출처로 삼아 정리했으며, 상세 화면마다 해당 링크를 명시합니다. 컨셉·인물·세계 서술은 공식 시놉시스와 캐릭터·프로덕션 소개를 바탕으로 한국어로 재작성한 것입니다.

`whatif` · `want` · `need` · `rule` · `spine`, 그리고 창작 패턴 8가지는 공식 문구를 그대로 옮긴 것이 아니라, **작품을 창작 교육 관점에서 분석·정리한 해석**입니다. 창작 원칙 22가지는 픽사 스토리 아티스트 엠마 코츠(Emma Coats)가 공개한 스토리텔링 원칙을 한국어로 옮기고 예시 작품을 붙인 것입니다.
