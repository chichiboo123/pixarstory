# 픽사 스토리 자판기

픽사 장편 애니메이션의 **작품 컨셉, 등장인물, 세계관**을 한곳에서 검색하고 비교하는 반응형 스토리 리서치 아카이브입니다. 자판기에서 상품을 고르듯 작품 코드를 입력하거나 포스터를 선택하고, 최대 네 작품의 창작 장치를 나란히 살펴볼 수 있습니다.

> 이 프로젝트는 픽사의 공식 서비스가 아닌 독립적인 창작 리서치 도구입니다. 작품 정보의 출처는 각 상세 화면에 연결된 Pixar Animation Studios 공식 페이지이며, 화면의 포스터는 저작권 보호를 위해 직접 만든 추상 SVG입니다.

## 주요 기능

- **진열대 탐색**: 연도순 작품 카드와 자동 생성 슬롯 코드(A1, A2 등)
- **빠른 검색**: 제목, 연도, 주제, 인물, 역할, 장소, 설명을 통합 검색
- **주제 필터**: 감정, 가족, 성장 등 작품별 핵심 주제로 범위 축소
- **자판기 키패드**: 행 문자와 번호 조합으로 작품 선택, 무작위 작품 뽑기
- **최근 출고구**: 최근 열어 본 작품을 중복 없이 최대 네 편 보관
- **상세 라벨**: 한 줄 컨셉, 이야기 출발점, 창작 장치, 인물과 세계 정보 제공
- **비교 트레이**: 최대 네 작품의 컨셉·인물·세계·규모를 가로 비교
- **반응형 UI**: 모바일에서는 검색/필터를 진열대보다 먼저 제공하고, 넓은 화면에서는 우측 조작 패널로 배치
- **접근성 지원**: 본문 바로가기, 키보드 탭 전환, 포커스 표시, 모달 포커스 고정 및 복원, 상태 알림, 모션 감소 설정 지원

## 실행 방법

별도의 빌드 과정이나 패키지 설치가 필요 없는 단일 HTML 애플리케이션입니다.

### 파일을 바로 열기

`index.html`을 브라우저에서 열면 됩니다. 다만 브라우저 정책과 개발자 도구 사용 편의를 위해 로컬 서버 방식을 권장합니다.

### Python 로컬 서버 사용

```bash
python3 -m http.server 4173
```

브라우저에서 <http://localhost:4173>에 접속합니다.

## 사용법

### 작품 찾기

1. 검색창에 작품명, 인물명, 장소 또는 주제를 입력합니다.
2. 주제 칩을 눌러 결과를 더 좁힙니다.
3. 결과 수는 조작 패널 아래에서 확인합니다.
4. 조건을 모두 지우려면 **검색·필터 초기화**를 누릅니다.

모바일에서는 검색과 필터가 카드보다 먼저 나오므로 긴 진열대를 스크롤한 뒤 조건을 바꿀 필요가 없습니다.

### 코드로 작품 뽑기

1. 키패드에서 알파벳 행을 먼저 누릅니다.
2. 이어서 숫자를 누릅니다.
3. 유효한 코드라면 상세 화면이 열리고 최근 출고구에 추가됩니다.

### 작품 비교하기

1. 작품 상세의 **비교 트레이에 담기**를 누르거나, 상단 **비교 트레이** 탭에서 작품 칩을 선택합니다.
2. 두 편 이상을 선택하면 항목별 비교 카드가 표시됩니다.
3. 최대 네 편까지 선택할 수 있습니다. 한도를 넘기면 기존 선택을 임의로 삭제하지 않고 안내 메시지를 표시합니다.
4. **선택 초기화** 또는 **무작위 3편 뽑기**로 빠르게 구성을 바꿀 수 있습니다.

## 키보드와 접근성

- `Tab`: 버튼, 검색창, 링크 순서대로 이동
- `←` / `→`: 진열대와 비교 트레이 탭 전환
- `Home` / `End`: 첫 번째 또는 마지막 탭으로 이동
- `Enter` / `Space`: 카드, 필터, 키패드 실행
- `Esc`: 열린 작품 상세 닫기
- 상세 화면 안에서 `Tab`을 계속 누르면 포커스가 모달 밖으로 빠져나가지 않습니다.
- 상세 화면을 닫으면 포커스가 원래 선택했던 카드 또는 버튼으로 돌아갑니다.
- 운영체제에서 **동작 줄이기**를 설정한 경우 출고 애니메이션과 전환 효과를 제거합니다.

### 추가로 권장하는 후속 개선

현재 범위를 넘어 데이터 또는 구조 변경이 필요한 항목입니다.

1. **URL 상태 공유**: 검색어, 주제, 비교 목록을 쿼리 문자열에 저장하면 조사 결과를 링크로 공유할 수 있습니다.
2. **즐겨찾기/세션 복원**: `localStorage`로 최근 출고와 비교 목록을 선택적으로 복원할 수 있습니다. 공용 기기에서의 개인정보·예상치 못한 상태 유지 문제를 고려해 명시적 옵션으로 제공하는 편이 좋습니다.
3. **데이터 분리**: 작품이 더 늘어나면 `FILMS`를 JSON으로 분리하고 스키마 검증을 추가해 콘텐츠 수정 오류를 줄일 수 있습니다.
4. **다국어 모드**: 현재 한국어 중심 구조에 영문 UI 전환을 추가하면 영문 작품명과 원문 태그라인 활용성이 높아집니다.
5. **자동화된 접근성 회귀 검사**: Playwright와 axe-core를 도입해 포커스, 이름/역할/값, 명도 대비를 CI에서 점검할 수 있습니다.

## 작품 추가 방법

`index.html`의 `FILMS` 배열에 객체를 추가합니다. 슬롯 코드, 검색 인덱스, 필터, 키패드 행, 비교 트레이는 작품 연도순 정렬 결과를 기준으로 자동 갱신됩니다.

필수/주요 필드는 다음과 같습니다.

```js
{
  id: 'wall-e',             // 고유 영문 식별자
  ko: '월-E',               // 한국어 제목
  en: 'WALL-E',             // 영문 제목
  year: 2008,
  theme: '환경·사랑',
  src: 'https://www.pixar.com/wall-e',
  tagline: 'Original tagline',
  taglineKo: '한국어 태그라인',
  palette: ['#000', '#111', '#222', '#fff'],
  poster: POSTER(...),      // 생략 시 AUTO_POSTER가 palette를 사용
  concept: '이야기의 출발점 설명',
  core: '창작 관점에서 눈여겨볼 장치',
  people: [{ n: '이름', r: '역할', d: '설명' }],
  worlds: [{ n: '장소', d: '설명' }]
}
```

### 콘텐츠 작성 원칙

- 공식 작품 페이지를 우선 출처로 사용합니다.
- 번역문은 직역보다 한국어 가독성을 우선하되 의미를 임의로 확장하지 않습니다.
- 인물과 세계 설명은 스포일러 수준을 일관되게 유지합니다.
- 포스터에는 공식 키아트를 복제하지 않고 작품의 색과 추상 모티프만 활용합니다.
- `id`는 중복되지 않아야 하며, 연도는 숫자로 입력합니다.

## 기술 구성

- HTML5
- CSS Custom Properties, Grid, Flexbox, 반응형 미디어 쿼리
- Vanilla JavaScript
- 인라인 SVG 포스터
- Pretendard 웹폰트 및 Material Icons (외부 CDN)

핵심 기능은 외부 프레임워크 없이 동작합니다. 네트워크 연결이 없으면 외부 폰트와 아이콘 스타일은 로드되지 않을 수 있지만 작품 데이터와 기본 인터랙션은 `index.html`에 포함되어 있습니다.

## 라이선스와 출처

- 작품명과 작품 관련 정보의 권리는 각 권리자에게 있습니다.
- 상세 화면의 출처 링크는 Pixar Animation Studios 공식 사이트로 연결됩니다.
- 본 저장소의 추상 SVG 포스터는 공식 포스터가 아닙니다.
- 배포 또는 재사용 전에는 저장소에 별도 라이선스가 있는지 확인하세요. 현재 명시적 라이선스 파일은 포함되어 있지 않습니다.
